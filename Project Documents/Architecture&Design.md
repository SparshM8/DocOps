Technical Requirements Document (TRD)Technology Stack:Frontend (UI/UX): Next.js with React, styled using Tailwind CSS for rapid mobile-responsive development.Backend (Core API): Node.js with Express to handle routing, user sessions, and database connections.AI/Data Science Engine: Python (FastAPI) microservice handling the LangChain/LlamaIndex framework, PDF parsing (PyMuPDF), and embedding generation.Database (Metadata): MongoDB to store user profiles, document upload history, and equipment tag relations.Database (Vector): Qdrant or Pinecone for storing and querying text embeddings.Architecture Flow: Next.js Client $\rightarrow$ Express API Gateway $\rightarrow$ (If document upload/query) $\rightarrow$ FastAPI AI Engine $\rightarrow$ Vector DB & LLM.
